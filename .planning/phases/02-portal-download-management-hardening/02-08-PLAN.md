frontend/src/Search.jsx today:
- `RETRYABLE = new Set(['failed', 'notReady', 'network', 'lost'])`
- `JOB_STATES = new Set(['started', 'preparing', 'rejected', 'unsupported', 'unavailable', 'duplicate', 'failed'])`
- `ROW_STATES = new Set([...JOB_STATES, 'expired', 'notReady', 'network', 'lost'])` (states a saved job may hold)
- `downloadErrorState(err)`: 410 expired, 503 notReady, 0 network, else failed
- `searchErrorMessage(err)`: 401 '', 503 MSG.notReady, 422 MSG.queryTooShort, 0 MSG.serverUnreachable, else MSG.searchFailed
- `applyJob` maps any status outside JOB_STATES to 'failed'; `pollJob` keeps polling while status is preparing

frontend/src/ResultRow.jsx: `MESSAGE = { rejected, unsupported, unavailable, expired, failed, notReady, network, lost }` each `{ text, tone, retry }`; a state with `retry: true` keeps the Download button enabled.
