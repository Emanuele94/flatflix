## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| request data -> log lines | search text, torrent names and addresses are attacker-influenced free text |
| process memory -> stdout | secrets live in Settings and in exception text; stdout is kept by Docker on the host |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-31 | Information disclosure | any log line | high | mitigate | Typed helpers (no request, body, header, cookie or settings object can be passed), no username on failed login, RedactingFilter on root and uvicorn handlers for the three secrets and both cookie patterns, canary test over the full flow |
| T-02-32 | Repudiation (log forging) | free text in audit lines | medium | mitigate | json.dumps with a 200-character cut escapes newlines and quotes; IPs bare only when address-shaped; canary test asserts every line starts with a timestamp |
