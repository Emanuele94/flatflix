<objective>
Make finished downloads actually move: a background verifier in the backend finds every completed Film/SerieTV torrent in quarantine, asks the sandbox about each video one at a time, judges the facts, and, when everything passes, hardlinks the files into the media folder and tags the torrent as verified while it keeps seeding. A runner that is down, a cancel, a vanished file or a changed file never lets anything through.

Purpose: QUAR-01 (nothing reaches media without passing), QUAR-04 (passing files move to their category's media folder), QUAR-02/QUAR-05 on the backend side (one interface, faults wait). Decisions D-45, D-46 (costly, settled), D-49, D-50, D-51, D-52, D-54, D-58, D-63.
Output: `Verifier`, `HandoffGuard`, the link hand-off, `QbitClient.add_tags`, lifespan wiring, two audit events, and FakeQbit support for save paths, file progress and tags.
</objective>
