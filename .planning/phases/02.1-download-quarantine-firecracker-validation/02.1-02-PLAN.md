<objective>
Build the sandbox runner: a small standard-library HTTP service that receives a path relative to the quarantine root, boots one throwaway Firecracker microVM with the file attached read-only and no network, reads ffprobe's nonce-framed answer from the serial console, and returns plain facts. It never judges a file; the backend does (D-70). This plan builds and tests it entirely with a stub `firecracker` executable, so it needs no KVM and no Docker; plan 02.1-05 puts it in the real image.

Purpose: QUAR-02 (fresh VM per file, no NIC, read-only file, limits, hard timeout, crash/timeout reported) and the "one stable interface" of QUAR-05. Decisions D-52, D-57/D-58 (fault taxonomy), D-69 (costly, settled), D-70, D-71 (amended: no jailer, the hardened container is the jail), D-72, D-75.
Output: `sandbox/runner/{paths,vm,server}.py` and `sandbox/tests/` with a stub-driven suite.
</objective>

  400 {"error": "invalid_json"} | {"error": "invalid_path"}   404 {"error": "not_found"}   409 {"error": "not_regular_file"}
  503 {"error": "runner_unavailable", "why": "kvm" | "artifacts" | "boot" | "permission"}

POST /selftest  same answers as /probe, for FX_SELFTEST_FILE

Guest console protocol (the guest init of plan 02.1-05 prints exactly this; the stub imitates it):
  FXP:<nonce>:BEGIN            printed by init before ffprobe starts
  FXP:<nonce>:EXIT:<rc>
  FXP:<nonce>:JSON  then the ffprobe JSON lines
  FXP:<nonce>:ERR   then at most 1 KiB of stderr, non-printable bytes replaced by '?'
  FXP:<nonce>:END
Kernel command line: console=ttyS0 reboot=k panic=1 pci=off loglevel=3 8250.nr_uarts=1 root=/dev/vda ro init=/init fxnonce=<hex> fxsize=<bytes>
ffprobe JSON shape read by the runner: {"format": {"format_name", "duration", "nb_streams", "size"}, "streams": [{"index", "codec_type", "codec_name", "width", "height", "disposition": {"attached_pic": 0|1}}]}

Environment (RunnerConfig.from_env, defaults in brackets): QUARANTINE_ROOT [/data/quarantine], FX_FIRECRACKER [/usr/local/bin/firecracker], FX_KERNEL [/opt/fx/vmlinux], FX_ROOTFS [/opt/fx/rootfs.ext4], FX_SELFTEST_FILE [/opt/fx/selftest.mkv], FX_VERSIONS_FILE [/etc/fx-versions] (lines key=value), FX_WORK_DIR [/run/fx], FX_KVM_DEVICE [/dev/kvm], VM_VCPUS [1], VM_MEMORY_MIB [256], VM_TIMEOUT_SECONDS [60], RUNNER_PORT [8090], MAX_CONSOLE_BYTES [262144], MIN_PROBE_BYTES [4096].

## Flagged assumptions

- RESEARCH A9 adjusted: the runner refuses to boot for files under 4096 bytes (reported as probe_failed too_small, a file fault) instead of the suggested 1 MiB floor, so short test clips and real fixtures stay probeable; no real film or episode is that small.
- Path traversal is canon: covered here by `resolve_probe_path` and by /gsd-secure-phase; not minted as a prohibition.
