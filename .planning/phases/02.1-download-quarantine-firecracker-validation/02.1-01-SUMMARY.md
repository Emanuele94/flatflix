- Tracer: Settings defaults, bootstrap categories, temp path and the single `${DATA_ROOT:-./data}` -> `/data` bind work end to end; a Phase 1-2 qBittorrent (categories on `/media/*`, temp path `/incomplete`) is repaired in one `repair_drift` call.
