<objective>
Move every new download into a quarantine folder that Jellyfin will never see, and lay out the host so the backend can later hardlink checked files into the media folders. One `DATA_ROOT` replaces the two old host roots, qBittorrent's categories save into `quarantine/<Category>`, the backend gets the same single bind and runs as the media owner, and the host script creates the new folders (with `rejected/` owner-only) and checks the `/dev/kvm` group the sandbox will need.

Purpose: QUAR-01 (quarantine outside the media folders) and the host half of QUAR-05 (KVM group, VM limit keys). Decisions D-44 (costly, settled), D-45, D-55 (folder mode), D-72 (limit keys). This plan also adds the whole configuration surface of the phase (thresholds, intervals, sandbox URL) so later plans never touch config.py, .env.example or test_config.py again.
Output: settings, compose binds, host script, env template, dev_env KVM_GID fill, the rewritten media contract doc, and the rebuilt dev stack with an all-OK doctor.
</objective>
