# Phase 02.1 Plan 02: Sandbox Runner Summary

**Standard-library sandbox runner that boots one offline, read-only Firecracker microVM per file, reads ffprobe's nonce-framed answer from the serial console, and returns plain facts (503 for host faults, statuses for file faults), proven end to end with a stub firecracker.**

## Accomplishments

- `POST /probe {"path": ...}` goes path resolution, tail file plus `vm.json`, `firecracker --no-api --config-file`, nonce-framed parse, facts JSON. The contract of the plan's interfaces block is implemented as written (D-69, D-70, QUAR-05).
- Every VM has no `network-interfaces` key, three read-only drives, `smt: false` and the 1 vCPU / 256 MiB defaults; a file whose size is a multiple of 512 gets a zero tail, one byte past a boundary gets that byte as the tail's first byte (QUAR-02).
- Host fault vs file fault split (D-57/D-58): missing artifacts, no KVM, unreadable file or folder, no BEGIN line all answer 503; BEGIN then timeout is 200 `timeout`; non-zero EXIT or bad JSON is 200 `probe_failed`.
- Timeout kills the whole process group and the work dir is empty afterwards; two parallel probes never overlap.
- No package or lockfile added: `git diff --exit-code -- backend/pyproject.toml backend/uv.lock` is clean (T-02.1-SC).

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] run_vm needs the nonce**
- **Found during:** Task 1
- **Issue:** The plan's `run_vm(cfg, config, workdir)` signature gives it nothing to pass to `parse_console`.
- **Fix:** `run_vm(cfg, config, workdir, nonce)`; `RunResult` also carries `console` and `console_len` (bytes kept, used by the cap test).
- **Files modified:** sandbox/runner/vm.py
- **Commit:** `8e6129a`, `6d971ec`

**2. [Rule 2 - Missing critical] PermissionError while resolving a path**
- **Found during:** Task 3 (writing the permission cases)
- **Issue:** A folder without search permission makes `lstat` raise `PermissionError`, which would drop the connection (a host fault must be a 503, D-58).
- **Fix:** server maps it to 503 `permission`; `probe_file` maps `PermissionError` on stat and on the tail read to `RunnerFault("permission")`; a Popen `OSError` is `boot`; an unusable work dir is `artifacts`.
- **Files modified:** sandbox/runner/server.py, sandbox/runner/vm.py
- **Commit:** `690bf72`

**3. [Rule 1 - Bug] Task 2 unit-test config lacked host artifacts after Task 3**
- **Found during:** Task 3 GREEN
- **Issue:** Six Task 2 tests built a `RunnerConfig` with no kernel, rootfs or KVM stand-in files; the new `check_artifacts` / `check_kvm` correctly refused them.
- **Fix:** `_cfg` in test_vm.py creates empty stand-in files and a KVM device file.
- **Files modified:** sandbox/tests/test_vm.py
- **Commit:** `690bf72`

**4. [Rule 2 - Design] /selftest skips the minimum-size floor**
- **Found during:** Task 3
- **Issue:** A real baked-in clip could be smaller than 4096 bytes and the selftest would answer too_small.
- **Fix:** optional `min_bytes` argument of `probe_file`; `/selftest` passes 1.
- **Commit:** `690bf72`

**5. [Plan sequencing] Tracer used `proc.kill()`, Task 3 replaced it with `os.killpg`**
- As the plan describes (Task 3 adds the group kill); noted for completeness.

**Total deviations:** 5 (1 blocking, 2 missing-critical/design, 1 bug in tests, 1 sequencing note). **Impact:** none on the contract; names and shapes of the interfaces block are unchanged.
