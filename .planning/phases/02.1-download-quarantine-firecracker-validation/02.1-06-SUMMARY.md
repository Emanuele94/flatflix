# Phase 02.1 Plan 06: Verifier, Hand-off and Lifespan Wiring Summary

**A backend loop that finds finished Film/SerieTV torrents in quarantine, probes each checked file one at a time in the sandbox, hardlinks them into media only when everything passed, and tags the torrent `fx-ok-<epoch>` while it keeps seeding; a runner outage, a cancel, a vanished torrent or a changed file never lets anything through.**

## Performance

- **Duration:** 8 min
- **Started:** 2026-10-23T19:52:20Z
- **Completed:** 2026-10-23T19:59:58Z
- **Tasks:** 2 (1 tracer, 1 TDD)
- **Files:** 4 created, 5 modified; no package or lockfile change

## Accomplishments

- `Verifier.run_once/check_torrent/run_forever` with `is_candidate`: oldest completion first, files in index order, one probe in flight, judged with the backend's own stat size and the per-kind minimum.
- The hand-off (`handoff.py`) is `os.link` only: it refuses absolute, empty, `.`/`..` and NUL names, symlinks below the save folder, symlinked media folders and a foreign file at the target; an existing same-inode target is skipped, so a half-finished hand-off completes on the next tick.
- The hand-off runs inside `HandoffGuard.lock(hash)`: cancel flag, torrent re-read (gone, no longer a candidate, other save path), and every file re-resolved and compared as (inode, size, mtime_ns) against its probe time. Only then links, then `addTags`.
- `RunnerUnavailable` stops the tick, sets `runner_down` and writes one `quarantine.runner_unavailable` line per outage; the next tick tries again.
- Lifespan: `create_app(settings, qbit, runner=None)` starts `verify_task` after the pipeline, cancels it before `jobs.shutdown()`, and closes the runner client before qBittorrent's.
- FakeQbit now reports `save_path`/`content_path`, file progress and has an `addTags` route.
