### `backend/app/quarantine/runner_client.py` (service, request-response)

**Analog:** `backend/app/qbit/client.py`

**Error hierarchy and transport mapping** (lines 20-33, 147-151):
```python
class QbitError(Exception):
    def __init__(self, *args: object, status: int | None = None) -> None:
        super().__init__(*args)
        self.status = status

class QbitUnavailable(QbitError):
    """qBittorrent cannot be reached or answered unexpectedly."""

async def _send(self, method: str, path: str, **kwargs) -> httpx.Response:
    try:
        return await self._http.request(method, path, **kwargs)
    except httpx.TransportError as exc:
        raise QbitUnavailable("qBittorrent is unreachable") from exc
```
**Constructor + factory** (lines 60-100): `transport: httpx.AsyncBaseTransport | None = None` injection for tests, `httpx.AsyncClient(base_url=..., transport=transport, timeout=..., follow_redirects=False)`, `from_settings(cls, settings)`, `aclose()`. Create `RunnerError` / `RunnerUnavailable` (maps transport errors and HTTP 503 `runner_unavailable`, D-58) and keep messages free of bodies (`_checked` pattern, lines 171-178). Return a typed dataclass of facts (status, format, streams, size_bytes), see `AddResult` (lines 43-53).

### `backend/app/quarantine/verifier.py` (service, poller loop)

**Analog:** `backend/app/qbit/bootstrap.py` `Bootstrapper` (injected `sleep`, `run_forever`, `on_ready`) at lines 166-196, and `backend/app/download/pipeline.py` for per-torrent locking and the qBittorrent read-decide-act order.

**Injectable-collaborator constructor** (bootstrap.py lines 166-181):
```python
class Bootstrapper:
    def __init__(self, qbit, settings, readiness, *, sleep=asyncio.sleep, on_ready=None) -> None:
        self._qbit = qbit; self._settings = settings; self._sleep = sleep
```
Follow it: `Verifier(qbit, runner, settings, outcomes, *, sleep=asyncio.sleep, clock=time.time)` so tests drive `run_once()` with no real wait. Serial queue (D-52) = one loop, no concurrency. Per-hash `asyncio.Lock` shared with cancel: pipeline uses `self._cancel_lock` (pipeline.py line ~364 `async with self._cancel_lock:`).

**Candidate rule** (RESEARCH Pattern 6): `row` in `READY_STATES` (listing.py 27-29), category via `type_for_category(settings, row["category"])` (as in `find_torrent`, listing.py 134-139), `save_path` under `settings.quarantine_root`, no tag starting `fx-ok-`. Tags via `tags_of(row)` (listing.py 65-66). Files via `qbit.torrent_files(hash)` (client.py 328-333), never `os.walk`.

**Errors:** catch `QbitError` per tick, `audit.error(where, type(exc).__name__, exc.status)` (audit.py 105-112); never log exception text.

## Shared Patterns

### Opaque ids, no paths to the browser
**Source:** `backend/app/download/listing.py` lines 113-124 (`download_id`), 127-139 (`find_torrent`). Apply to: outcome sidecar names, `rejected/<id>/` folders, list items. Never emit hash, save path or category (also `backend/tests/test_no_leaks.py`).

### Audit trail
**Source:** `backend/app/audit.py` lines 42-56, 75-112. Apply to: verifier, handoff, purge. File and torrent names only through `_text()`, enums through `_token()`; no exception text, only class name and status.

### qBittorrent access and error handling
**Source:** `backend/app/qbit/client.py` lines 171-178 (`_checked`), 20-41 (`QbitError` family). Apply to: verifier loop, purge; catch `QbitError` per tick and continue, do not crash the task.

### Settings from env with validators
**Source:** `backend/app/config.py` lines 68-74, 83-84, 205-213. Apply to: every new path, threshold and timeout; error text names the variable and never echoes the value.

### Background task in lifespan
**Source:** `backend/app/main.py` lines 63-83. Apply to: verifier loop (create, keep strong ref, cancel and await with `contextlib.suppress`).

### Fail closed
Pass only on `status == "ok"` plus judge Pass; runner 503/transport error leaves the row in Checking (D-58); hardlink `OSError` leaves it in Checking (D-48). No copy fallback anywhere.

### Compose long-syntax bind with `create_host_path: false`
**Source:** `docker-compose.yml` lines 27-41. Apply to: `DATA_ROOT` bind (qbittorrent, backend) and the sandbox quarantine mount (add `read_only: true`).
