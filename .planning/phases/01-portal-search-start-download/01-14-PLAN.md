|----------|-------------|
| search plugin output -> qBittorrent add | Untrusted plugin pages decide whether a magnet or a .torrent is added; the add params decide whether payload can flow before the allowlist |
| backend -> qBittorrent WebAPI | The add form is the only control over pre-allowlist payload |
| real-engine guard -> internet torrent sites | Opt-in test reaches public indexers and swarms |
