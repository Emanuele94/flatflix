## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> /api/search | Untrusted query and type |
| backend -> qBittorrent plugins | The query is handed to third-party plugin code |
| plugins -> browser | Result names are attacker-controlled text rendered on the phone |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-25 | Tampering | POST /api/search type | high | mitigate | Strict `Literal["film","serie"]` + extra="forbid"; category derived only from app.content_type; tests assert zero qB calls on invalid input (qB auto-creates any category, Pitfall 4) |
| T-01-26 | Tampering | query passed to plugins | medium | mitigate | Cc/Cf stripped, 2..100 code points; canon injection concerns referred to /gsd-secure-phase (A11) |
| T-01-27 | Denial of service | qBittorrent 5-search limit | medium | mitigate | max 3 active searches, oldest stopped+deleted, 409 recovery, delete on done, timeout stop |
| T-01-28 | Tampering | result names in the SPA (XSS) | medium | mitigate | Preact text rendering only, no dangerouslySetInnerHTML (grep criterion), CSP script-src 'self' from 01-04, XSS test |
| T-01-29 | Information disclosure | search responses | high | mitigate | Explicit DTO whitelist; file URLs and engine data stay in the server-side cache; key-set test and smoke check |
| T-01-SC | Tampering | packages | high | mitigate | No new packages; approved lockfiles only |
</threat_model>
